GND: pins 6, 9, 14, 20, 25, 30, 34, 39. Never connect pins 1, 2, 4 or 17 (3.3 V / 5 V) to a GPIO. Every external target goes through the 74LVC245 buffer with a shared ground, and unused buffer inputs are tied to GND.

Capture

Presets:

The capture runs until you press Stop unless you set a limit. Samples are written as they arrive, so length is bounded by disk space, not memory. Silence timeout waits for the first change on any channel, then ends the capture once the line has been quiet that long. Monitor keeps sampling all the time but writes only the bursts: each one gets its own file with a lead-in before the first change and a tail after the last, and the silence between bursts is recorded in the index instead of on disk.

Live decode

sigrok's decoders run in Python, so keep the rate low: about 2 MSa/s handles 115200 baud comfortably.
